# Изменения DYNASTY FAMILY

- Пять полей анкеты: ник; статик # (ASCII цифры); имя и возраст IRL; выпадающий список Crime/State; информация о семье.
- Автоматическая выдача одной из двух ролей по выбранному направлению.
- Приватные ветки прямо под `#подать-заявку`; отдельный `#проверка-заявок` больше не используется для новых анкет.
- Личные сообщения заявителю: получена, одобрена, отклонена (с учётом закрытых ЛС).
- Картинка пользователя в начальном Embed как Discord-вложение.
- Новая `/set_application_roles` для обновления уже настроенных серверов без потери существующих голосовых комнат.
- Миграция существующей базы SQLite без удаления старых данных.
- Голосовые комнаты и 13 кнопок управления сохранены.
