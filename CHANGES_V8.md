# DYNASTY FAMILY Bot v8 — выбор даты и результата капта

Обновление для Majestic RP Miami. **Контракты не добавлялись.** Все системы из v7 остаются на месте, включая `/menu`, `/profile`, заявки, обзвоны, временные комнаты, напоминания 30/15/5 минут и достижения.

## 1. Завершение капта — без ручного ввода результата

1. Капитан или администратор открывает сообщение капта и нажимает **«Завершить»**.
2. В приватном сообщении от бота появляется выпадающий список **«Выберите результат капта»**.
3. Выбирает **🏆 Победа**, **❌ Поражение** или **🤝 Ничья**.
4. Бот открывает форму, в которой осталось только два необязательных поля: **ссылка на запись** и **комментарий**.
5. После отправки бот сохраняет выбранный результат, обновляет Embed, журнал каптов, рейтинг и статистику профиля (по подтверждённой явке).

Выбирать результат вручную текстом больше не нужно. После завершения одного капта результат повторно не записывается.

## 2. Создание капта — выбор даты и времени

1. Капитан нажимает **«Создать капт»** на панели или в `/menu` → «Капт-состав».
2. В форме заполняет **противника**, **место/квадрат**, **формат** и **количество мест**.
3. Бот отправляет приватное меню выбора:
   - **📅 Дата:** выпадающий список на 25 дней. Для будущих дат есть кнопки **«← Предыдущие даты»** и **«Следующие даты →»** (в пределах 365 дней вперёд).
   - **🕒 Часы:** 00–23.
   - **⏱️ Минуты:** 00–55, шаг 5 минут.
4. После выбора нажимает **«✅ Опубликовать капт»**.
5. Бот публикует новый капт в настроенном канале со всеми прежними кнопками, ролью анонсов и таймерами напоминаний.

Discord в применяемом интерфейсе не предоставляет стандартный календарь с сеткой дней. Поэтому реализован **выпадающий список дат**, а не визуальный календарь. Вводить дату и время вручную не требуется.

Часовой пояс задаётся в `/menu` → «Капт-состав» → **«Часовой пояс»**. Бот не позволит создать капт в прошлом и проверит несуществующее локальное время при переводе часов. Выбор времени ограничен пятиминутным шагом.

## 3. Обновление через GitHub — пошагово

1. На хостинге нажми **Stop**. Скачай резервную копию `data/bot.sqlite3`.
2. Распакуй архив **`DYNASTY_FAMILY_v8_UPDATE.zip`**.
3. На GitHub открой свой репозиторий и замени **только** `family_features.py` новым файлом из архива.
4. По желанию замени `README.md`, добавь `CHANGES_V8.md` и тест `tests/test_capt_ui_v8.py`.
5. Нажми **Commit changes**.
6. В хостинге выполни **Redeploy/Rebuild**: обычный Restart иногда не забирает новые файлы из GitHub.
7. Открой логи, убедись, что бот запущен. Команды остаются `/menu` и `/profile` (новые команды не требуются).
8. В Discord проверь «Создать капт» и «Завершить» на тестовом капте.

**Dockerfile в v8 менять не нужно:** новые зависимости/файлы не добавлены, изменился только `family_features.py`.

Нельзя загружать секретный `.env` в GitHub или удалять SQLite. При многосерверной установке сохраняется `GUILD_ID=0`, если это уже было настроено.

## 4. Проверка

Локально прошли 37 проверок, включая 31 тест из v7 и 6 дополнительных для интерфейсов v8 (валидность результата, список дат, переход между страницами, ограничения времени). Синтаксис Python проверен. **Запуск с реальным Discord API на действующем сервере в этой среде не выполнялся.**
